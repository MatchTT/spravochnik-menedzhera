# Справочник менеджера PromoPult · Рег1

Внутренний сайт для менеджеров: звонки, мессенджеры, бонусная программа, вопросы и возражения.

- Цифры бонусной программы меняются в одном месте: `assets/app.js`, блок `BONUS` в самом начале файла.
- Вопросы и возражения лежат в `assets/faq.js`.
- Папка `_build` — служебная: из неё собираются страницы. Руками её трогать не нужно.
