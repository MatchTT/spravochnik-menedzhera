Шаблоны сообщений Salesbot для воронки рег.1

Документ содержит согласованные тексты сообщений для ручного запуска каскада в amoCRM. Для каждого сценария предусмотрены варианты с обращением по имени клиента и без имени.

ПеременнаяЧто подставляется
{{contact.first_name}}Имя клиента из карточки контакта
[Имя менеджера]Только имя ответственного менеджера без фамилии; подставляется отдельной веткой Salesbot по ответственному

Правило выбора варианта. Сообщение с именем используется только при корректном имени в карточке контакта. Если указаны ник, набор символов, некорректное выражение или имя отсутствует, выбирается вариант без имени.

Важно для настройки Salesbot. Стандартная переменная {{lead.responsible.name}} не используется, поскольку она подставляет полное имя пользователя. В Salesbot создаются отдельные ветки по ответственному: Лилия, Денис, Дарья, Чолпон и Саша. В сообщение подставляется только соответствующее имя без фамилии.
